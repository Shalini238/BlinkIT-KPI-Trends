# 🛒 Blinkit Grocery Sales Analysis Dashboard

## 📌 Project Overview

The Blinkit Grocery Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance, customer ratings, and inventory distribution. The dashboard helps identify business trends, compare outlet performance, and support data-driven decision-making through visually appealing reports.

---

## 🎯 Business Objective

To conduct a comprehensive analysis of Blinkit's sales performance, customer satisfaction, and inventory distribution by using key performance indicators (KPIs) and interactive visualizations to uncover valuable business insights. :contentReference[oaicite:0]{index=0}

---

## 📊 Key Performance Indicators (KPIs)

- 💰 Total Sales
- 📈 Average Sales
- 📦 Number of Items Sold
- ⭐ Average Customer Rating

---

## 📈 Dashboard Features

### 1. Sales by Fat Content
- Compare Low Fat and Regular products.
- Analyze their contribution to total sales.

### 2. Sales by Item Type
- Identify top-performing product categories.
- Compare sales across different item types.

### 3. Outlet Establishment Analysis
- Analyze sales trends based on outlet establishment year.

### 4. Outlet Size Analysis
- Compare sales across Small, Medium, and High outlet sizes.

### 5. Outlet Location Analysis
- Compare sales across Tier 1, Tier 2, and Tier 3 cities.

### 6. Outlet Type Performance
- Analyze Total Sales
- Average Sales
- Number of Items
- Average Rating

### 7. Interactive Filters
Users can filter dashboard data by:
- Outlet Location Type
- Outlet Size
- Item Type
